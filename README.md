# Lernraum

Redesign-Konzept für eine schulische Materialablage im modernen Apple-UI-Look.

Gleiche Grundstruktur wie ein klassisches Schul-Datenablagesystem (Fächer → Materialien),
aber mit Platzhalter-Dateien statt echter Uploads, einer Finder-artigen Oberfläche und
zusätzlichen Funktionen: Spotlight-Suche (⌘K), Quick-Look-Vorschau, Favoriten, fällige
Materialien, Lesefortschritt, Papierkorb mit 30-Tage-Frist, Mehrfachauswahl und ein
Hell-/Dunkel-/Automatik-Farbschema.

Reines Frontend-Konzept (statisches HTML/CSS/JS), gebaut zu Pitch-Zwecken.
